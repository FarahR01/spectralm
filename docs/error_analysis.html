BLEU vs ECR tradeoff
Central finding: removing physics constraints raises BLEU 0.612 → 0.631 (+3%) but raises ECR 0.042 → 0.187 (+4.5×) — a better text predictor, but scientifically unreliable. ECR automatically catches 67% of all failures (Types I, III, IV). Type II (regioisomers) requires complementary NMR data — a fundamental limitation of infrared spectroscopy itself, not a model failure.
